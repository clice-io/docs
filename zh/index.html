下一代 C++ 工具链

C++ 的工具生态一直很混乱。我们正在开发一组全新的 C++ 工具来改变它：一个读懂整个项目的语言服务器，一个能从任何构建里拿到编译命令的拦截器，一套开箱即用的交叉编译 Clang 工具链，以及撑起它们的 C++23 基础库。

上手 clice →

项目

命令交到 clice 手里。它读懂整个项目，回应你的编辑器：VS Code、Neovim、Zed。

clice

语言服务器

头文件上下文、C++20 模块、模板内补全都不在话下，Clang 崩溃也不会拖垮它。

看文档 →

某处，一次构建开始了：CMake、Meson、Bazel、Make……

catter

构建拦截器

拦截构建派生的每个进程，为任何构建系统生成 compile_commands.json，还能分析构建耗时。

看文档 →

而撑着它们俩的，是 kotatsu。

kotatsu

C++23 基础库

基于 libuv 的协程运行时、编译期反射、带 LSP 绑定的类型化 IPC、选项解析和 CLI。

去 GitHub ↗

而把这一切编译出来的，是 xclang。

xclang

Clang 工具链

一个压缩包装下 Clang 和八个目标的 sysroot 与运行时：Linux、Windows、macOS，x64 与 arm64 各一份。交叉编译只需一个 --target，import std 开箱即用。
