悬停 ​

光标下符号的富信息卡片。

符号信息 ​

  • 限定名 — 悬停卡片显示所属命名空间和类作用域

    示例
    cpp
    namespace app::detail {

struct Engine {
    void tick() {
        int count = 0;
    }
};

int workers = 4;

}

int global = 1;

  • 符号种类 — 卡片说明符号是什么：struct、enum、function、field 等

    示例
    cpp
    namespace kinds {

struct Point {
    int x;
};

union Packet {
    int raw;
};

enum class Color {
    Red,
};

using Alias = Point;

int length(Point p) {
    return p.x;
}

}

  • 访问说明符 — 成员显示其 public / protected / private 访问级别

    示例
    cpp
    class Account {
public:
    int balance;

protected:
    int limit;

private:
    int pin;
};

  • 定义渲染 — 卡片包含符号的源码定义

    示例
    cpp
    namespace retry {

constexpr int max_retries = 3;

int backoff(int attempt = 1) {
    return attempt * max_retries;
}

}

  • 初始化器截断 — 大型初始化器截断显示，而不是完整显示 (部分) (clangd#710)

    渲染出的定义省略了初始化器，但求值后的 Value 字段仍然列出全部 256 个元素。

    示例
    cpp
    #define A(x) x, x, x, x
#define B(x) A(A(A(A(x))))
int arr[] = {B(0)};

  • 虚修饰符 — 方法悬停显示 virtual / override / final (部分) (clangd#2474)

    源码中写出的修饰符会渲染出来（virtual … = 0、override、final），但重写方法如果省略了冗余的 virtual 关键字，就看不到虚函数的迹象——卡片缺少 issue 要求的 virtual void draw() override 形式。

    示例
    cpp
    struct Base {
    virtual void draw() = 0;
};

struct Circle : Base {
    void draw() override;
};

struct Dot final : Circle {
    void draw() final;
};

  • 匿名命名空间作用域 — 作用域显示中显示 (anonymous namespace) (部分) (clangd#436)

    卡片会渲染，但匿名段从作用域显示中丢掉了：顶层匿名成员完全不显示作用域行，outer::(anonymous) 只显示 outer。

    示例
    cpp
    namespace {
int hidden = 1;
}

namespace outer {
namespace {
int nested = 2;
}
}

int sum = hidden + outer::nested;

类型信息 ​

  • 变量类型 — 指针、引用、数组

    变量的卡片对声明类型进行美化打印，按照源码中的读法拼出指针、引用和数组声明符。

    示例
    cpp
    namespace variable_type {

int target;

int *ptr = &target;

int &ref = target;

int numbers[4]{};

}

  • 类型别名 — 脱糖后的 aka 形式

    带糖的类型把底层类型显示为 Alias (aka int)。show_aka 选项可以关掉 aka 后缀。

    示例
    cpp
    namespace aka_desugar {

using Handle = int;
using Alias = Handle;

Handle direct = 0;

Alias chained = 0;

}

  • 函数签名 — 返回类型、参数名、默认值

    函数卡片列出返回类型、每个参数及其名称，以及任何默认实参。

    示例
    cpp
    namespace function_signature {

int add(int lhs, int rhs);

void configure(int width, bool visible = true);

}

  • 模板参数 — 类型、模板模板、非类型

    每种模板参数都会报告其形式：类型参数、模板模板参数，以及带默认值的非类型参数。

    示例
    cpp
    // Template type parameter.
namespace type_param {
template <typename T = int> void foo();
}

// Template template parameter.
namespace template_template_param {
template <template<typename> class T> void foo();
}

// Non-type template parameter.
namespace non_type_param {
template <int T = 5> void foo();
}

  • auto 推导 — 占位符解析成的类型

    悬停 auto 占位符会显示替换进去的类型——内置类型、指针、lambda、模板实例化，以及未实例化模板中的 /* not deduced */ 标记。

    示例
    cpp
    namespace auto_deduction {

struct Bar {};
struct Pair { int first; int second; };
template <typename T> struct Box {};

void locals() {
  int n = 0;
  auto a = 1;
  const auto b = 1;
  auto& c = n;
  auto* d = &n;
  auto e = &n;
  auto f = []{};
  auto g = Box<int>();
  auto [x, y] = Pair{};
}

auto with_trailing() -> int { return 0; }

auto deduced_return() { return Bar(); }

template <typename T> void undeduced() {
  auto u = T();
}

}

  • decltype 推导 — 值、引用和依赖形式

    悬停 decltype 或 decltype(auto) 占位符会显示解析出的类型，包括括号表达式规则添加的引用。

    示例
    cpp
    namespace decltype_deduction {

int base = 0;

void locals() {
  int n = 0;
  const int cn = 0;
  int& r = n;
  decltype(auto) a = 1;
  decltype(auto) b = cn;
  decltype(auto) c = r;
  decltype(n) d = n;
  decltype((n)) e = n;
  decltype(static_cast<int&&>(n)) f = static_cast<int&&>(n);
}

decltype(base) mirror = base;

template <typename T> decltype(auto) undeduced() { return T(); }

template <typename T> struct Dependent {
  using kind = decltype(T::member);
};

}

  • CTAD — 类占位符推导出的模板参数 (部分) (clangd#435)

    使用类模板实参推导时，变量卡片会显示推导出的 Box<int>，但悬停类名拼写仍然报告不带实参的主模板。

    示例
    cpp
    namespace ctad_arguments {

template <typename T> struct Box {
  Box(T);
};

Box picked(42);

}

  • 实例化实参 — 模板参数在使用处绑定 (部分) (clangd#230)

    模板使用处会显示替换后的类型（Wrapper<int>、identity<int>、int x），但不会显示每个参数绑定到哪个实参的显式 T = int 映射。

    示例
    cpp
    namespace instantiation_args {

template <typename T> struct Wrapper {
  T value;
};

template <typename T> T identity(T x) {
  return x;
}

void demo() {
  Wrapper<int> holder;
  int r = identity(42);
}

}

  • Lambda auto 参数——推导出的参数类型 (clangd#493)

    悬停泛型 lambda 的 auto 参数不会产生卡片； 推导出的参数类型不会显示。

    示例
    cpp
    namespace lambda_auto_params {

auto printer = [](auto value) { return value; };

}

  • 糖化 auto——推导过程中保留别名糖

    clangd 将 auto 丢失别名糖的问题跟踪为 clangd#709；clice 已保留别名拼写并附加其脱糖形式，因此 从别名返回类型推导的 auto 显示为 Outer // aka: int。

    示例
    cpp
    namespace sugared_auto {

using Inner = int;
using Outer = Inner;

Outer make();

void demo() {
  auto value = make();
}

}

  • 类型格式化——对渲染的类型应用 clang-format (clangd#2156)

    长或嵌套的类型由编译器的默认类型打印器打印； 它们不会通过 clang-format 重新换行或对齐。

    示例
    cpp
    namespace clang_format_types {

template <typename A, typename B, typename C, typename D>
struct Tuple {};

Tuple<int, long, unsigned, char> wide;

}

  • 匿名结构体 typedef——经典 C typedef struct {…} Name (clangd#2219)

    按 C11 编译：clangd 对匿名结构体的别名渲染出误导性的 struct Point； clice 将该结构体以其 typedef 命名， 因此别名及其变量都得到干净的 Point 卡片。

    示例
    cpp
    /// A 2-D point.
typedef struct {
  int x, y;
} Point;

Point origin = {.y = 2, .x = 1};

  • 概念约束——参数或 auto 占位符背后的约束 (部分)

    受约束参数和概念引用卡片带有约束， 但悬停受约束的 Addable auto 变量的占位符时只显示推导类型——约束被丢弃了。

    示例
    cpp
    namespace concept_constraints {

template <typename T>
concept Addable = requires(T a) { a + a; };

template <Addable U>
void sum(U a, U b);

auto flag = Addable<int>;

Addable auto total = 1;

}

布局信息 ​

  • 字段布局——大小、偏移、对齐和填充在字段悬停时显示

    语料库固定为 x86-64 目标，因此位数是稳定的。

    示例
    cpp
    struct Header {
    char tag;
    int length;
};

struct Flags {
    int ready : 1;
    int end : 1;
};

  • 类型级布局——悬停类型本身显示其大小、对齐和填充 (部分) (clangd#1763)

    大小和对齐目前显示在类型卡片上； 总填充还没有显示。

    示例
    cpp
    namespace layout {

struct Widget {
    int id;
    double value;
};

}

  • 虚函数表偏移 — 虚方法显示其表槽 (partial) (clangd#1771)

    目前方法卡片不渲染任何 vtable 信息。

    示例
    cpp
    struct Shape {
    virtual void draw();
    virtual void move();
};

表达式上下文 ​

  • 常量求值 — constexpr、枚举器、sizeof

    当初始化器是常量表达式时，卡片会求值并显示结果值。

    示例
    cpp
    namespace constant_value {

constexpr int square(int n) { return n * n; }
int from_call = square(5);

int from_sizeof = sizeof(int);

enum Color { Red = -1, Green = 5 };
Color picked = Green;

template <int A, int B> struct Sum { static constexpr int value = A + B; };
int from_member = Sum<3, 4>::value;

}

  • 调用实参 — 每个实参绑定到哪个形参

    在调用点悬停实参时，会显示其传入的形参，并标明其绑定的形参名。

    示例
    cpp
    namespace callee_arguments {

void configure(int width, int& out, int flags = 0);

void demo() {
  int w = 1024;
  int result = 0;
  configure(w, result, 3);
}

}

  • 传递语义 — 按值、按引用、按 const 引用

    实参卡片说明值如何到达被调用者：按值复制，或绑定到可变或 const 引用形参。

    示例
    cpp
    namespace pass_semantics {

void by_value(int x);
void by_ref(int& x);
void by_const_ref(const int& x);

void demo() {
  int n = 0;
  by_value(n);
  by_ref(n);
  by_const_ref(n);
}

}

  • 隐式转换 — 实参转换为形参类型

    当实参通过隐式转换传给形参时，卡片会标注目标类型，无论是内建转换还是用户自定义转换。

    示例
    cpp
    namespace implicit_conversion {

struct Wrapper {
  Wrapper(int value);
};

void take_float(float x);
void take_wrapper(Wrapper w);

void demo() {
  int n = 0;
  take_float(n);
  take_wrapper(n);
}

}

  • 字符串字面量 — 悬停时报告长度 (partial) (clangd#1016)

    字符串字面量卡片报告数组类型及其字节大小（const char[6]、Size: 6 bytes——长度加上 null 终止符），而不是显式的字符数。

    示例
    cpp
    namespace string_length {

const char *greeting = "hello";

}

  • 数值字面量 — 整数或浮点字面量的类型和值 (clangd#1669)

    悬停数值字面量不会产生卡片，而字符和字符串字面量的类型和值会显示。

    示例
    cpp
    namespace numeric_literal_type {

auto count = 42;
auto ratio = 3.14;

}

  • Record 变量 — 外层常量值混入（部分）（clangd#1622）

    悬停一个可常量求值调用的 record 类型实参时，当前会把该调用的值（Value = 7）报告到该变量上——这个值并不是该 record 自身的值。

    示例
    cpp
    namespace record_value_misleading {

struct Tag {};

constexpr int rank(Tag) {
  return 7;
}

void demo() {
  Tag t;
  int r = rank(t);
}

}

文档 ​

  • Doxygen /// 注释 — 从声明中提取，并在悬停时渲染

    适用于普通函数、主模板及其特化；引用会解析到最特化声明的注释。

    示例
    cpp
    namespace docs {
/// Adds two integers.
int add(int a, int b);

/// A box holding a value.
template <typename T> struct Box {};

/// A box of pointers.
template <typename T> struct Box<T*> {};

void use() {
    Box<int> b;
    Box<int*> p;
}
}

  • 合成访问器文档 — 简单 getter/setter 获得一行生成的描述

    自身没有注释的简单 getter 或 setter 会在其悬停卡片中生成一行合成的 "Trivial accessor/setter for field." 文本。

    示例
    cpp
    namespace accessors {
struct Widget {
    int width;
    int getWidth() { return width; }
    void setWidth(int w) { width = w; }
};
}

  • @copydoc 标签 — 将另一个符号的文档复制到当前符号上（部分）（clangd#1320）

    @copydoc target 标签应将 target 的文档复制到当前符号的悬停卡片中。clice 目前还不解析该标签——卡片显示的是字面文本 @copydoc base_func()。

    示例
    cpp
    namespace copydoc {
/// Detailed documentation.
void base_func();

/// @copydoc base_func()
void wrapper();
}

  • 继承的重写方法文档 — 没有注释的 override 应显示基类方法的文档（部分）（clangd#2504）

    悬停一个自身没有注释的重写方法时，应显示它所重写方法的文档。clice 目前还不继承该文档——重写方法的卡片中没有任何描述。

    示例
    cpp
    namespace inherit_docs {
struct Base {
    /// Renders the widget.
    virtual void draw();
};
struct Circle : Base {
    void draw() override;
};
}

  • 重载文档共享 — 后续没有注释的重载应复用第一个重载的文档（部分）（clangd#2506）

    连续的重载通常只给第一个写文档；后续未写文档的重载应复用这份共享描述。clice 目前还不共享该文档——后续重载的卡片中没有任何描述。

    示例
    cpp
    namespace overloads {
/// Opens a file.
void open(const char* path);
void open(const char* path, int flags);
}

  • 继承构造函数文档 — using Base::Base; 应显示基类构造函数的文档（clangd#1936）

    通过 using Base::Base; 引入的构造函数在悬停时应带有基类构造函数的文档。目前没有对应的悬停界面：using 声明中的名字解析到类，而不是继承的构造函数。

    示例
    cpp
    namespace inherited_ctor {
struct Base {
    /// Constructs from a value.
    Base(int value);
};
struct Derived : Base {
    using Base::Base;
};
}

  • 横幅注释 — 与后文用空行分隔的段落横幅不应附着到下一个声明（部分）（clangd#974）

    // ==== Section ==== 这样的横幅后跟空行时，不应被误当作其下声明的文档。clice 目前仍会附着它——横幅文本会出现在卡片中。

    示例
    cpp
    namespace banners {
// ==== Section Banner ====

void foo();
}

  • 声明与定义注释 — 优先使用声明的文档，而不是定义处的注释

    clangd 将其跟踪为 clangd#829；clice 已经优先使用声明处的 /// 文档，而不是定义处的普通 // 注释，并在声明处和定义处都显示它。

    示例
    cpp
    namespace decldef {
/// Public API documentation.
void process(int x);

// Internal implementation note.
void process(int x) { (void)x; }
}

  • 空白和换行 — 注释中的 markdown 表格保留其换行（部分）（clangd#2057）

    跨多行 /// 编写的 markdown 表格应按保留换行的方式渲染为表格。clice 目前将多行压成一行，因此表格无法渲染。

    示例
    cpp
    namespace tables {
/// | Column A | Column B |
/// |----------|----------|
/// | 1        | 2        |
void table_fn();
}

  • 注释缩进 — 注释中缩进的文本行不应产生多余的额外缩进（部分）（clangd#1040）

    文档注释正文包含缩进代码块时，应以正确的缩进渲染。clice 目前会去掉前导缩进，导致缩进代码块丢失偏移量，空行也会塌陷。

    示例
    cpp
    namespace indented {
/// Summary line.
///
///     step_one();
///     step_two();
void run();
}

  • 宏展开产生的 template 关键字 — 文档注释应在展开后保留 (部分) (clangd#1226)

    当 template 关键字来自宏展开时，声明的文档注释仍应出现在 hover 中。clice 目前会丢弃它——卡片没有描述。

    示例
    cpp
    int anchor = 0;

#define TEMPLATE template

/// A documented template function.
TEMPLATE <typename T> void run(T value);

  • 注释抑制选项 — 配置开关，用于隐藏错误归属的文档注释 (clangd#2148)

    被关联启发式误拾取的散落注释——例如与代码之间隔一空行的节横幅——总是出现在 hover 卡片上：clice 没有配置选项来抑制归属为猜测的文档注释。

    示例
    cpp
    namespace suppression {
// TODO: tidy this file up.

int counter;
}

宏悬停 ​

  • 各处的定义文本 — #define、使用处、#ifdef 和 #undef 都显示宏的定义

    宏的 hover 卡片在其名称出现的任何地方都带有 #define 文本：定义本身、使用处、#ifdef 守卫和 #undef。

    示例
    cpp
    int anchor = 0;

#define LIMIT 64

int use = LIMIT;

#ifdef LIMIT
int guarded = 1;
#endif

#undef LIMIT

  • 完全展开预览 — 函数式宏使用处显示其参数代入宏体后的结果

    悬停函数式宏调用会显示 #define 文本，以及将调用实参代入后完全展开结果的预览。

    示例
    cpp
    int x = 1, y = 2;

#define MAX(a, b) ((a) > (b) ? (a) : (b))

int z = MAX(x, y);

  • 命令行宏 — -D 定义在 hover 中会带有合成的 #define

    在命令行定义的宏（-DFROM_CLI=7）会在其 hover 卡片中显示合成的 #define FROM_CLI 7，然后显示其展开。

    示例
    cpp
    int cli = FROM_CLI;

  • 实参中的嵌套宏 — 在另一宏调用的实参内命名的宏 (部分)

    记录的展开从外层调用开始，因此悬停实参内命名的内层宏只会显示其定义，不会显示展开预览。

    示例
    cpp
    int anchor = 0;

#define ECHO(x) x
#define INNER_VAL 99

int nested = ECHO(INNER_VAL);

  • 定义前使用 — 悬停出现在其 #define 之前的宏名称 (部分) (clangd#2642)

    在其自身 #define 之上的 #if 中使用的宏名称仍应在 hover 中显示宏的定义。clice 目前在定义前使用处不返回 hover；#define 之后的使用正常。

    示例
    cpp
    int anchor = 0;

#if COUNT > 0
int positive = 1;
#endif

#define COUNT 3

int use = COUNT;

  • preamble 内的 #define — 悬停位于文件开头的指令

    文件 preamble 区域（第一个声明之前的前导指令串）中的 #define 不属于实时解析的预处理器记录，因此悬停其名称不会有任何结果。其他每个宏 fixture 都以声明开头，正是为了将其指令推到 preamble 边界之外。

    示例
    cpp
    #define EARLY 1

int use = EARLY;

特殊悬停目标 ​

  • 类型悬停上的成员 — 悬停枚举或结构体类型时列出其成员 (部分) (clangd#959)

    卡片会显示类型名称（以及结构体的布局），但成员列表不会展开——主体渲染为 {}。

    示例
    cpp
    namespace members {

enum Color {
    Red,
    Green,
    Blue,
};
