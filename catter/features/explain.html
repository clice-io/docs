Explain ​

catter explain prints how catter analyzes one command, without running it: which compiler or archiver it recognizes, the compiler's mode and target, and the files the command reads and writes. It answers why a command gets, or does not get, an entry in the compilation database.

Command: explain

Usage ​

bash
catter explain [options] -- <command>

Options ​

OptionDescription
-C, --directory <path>The directory the command runs in. Default: the current directory.

Output ​

A JSON object. For a compiler:

bash
catter explain -- gcc -c a.c
json
{
  "analyzer": "compiler",
  "compiler": "builtin:gcc",
  "dialect": "gcc",
  "phase": "compile",
  "artifact": "object",
  "target": {
    "os": "linux",
    "objectFormat": "elf",
    "artifactModel": "elf",
    "from": "host-fallback"
  },
  "sources": ["a.c"],
  "reads": ["a.c"],
  "writes": ["a.o"],
  "edges": [{ "output": "a.o", "inputs": ["a.c"] }],
  "inferred": [{ "path": "a.o", "reason": "default-output" }],
  "entries": [
    {
      "directory": "/work",
      "file": "a.c",
      "arguments": ["gcc", "-c", "a.c"],
      "output": "/work/a.o"
    }
  ]
}
FieldMeaning
analyzercompiler, archiver, or null when no analyzer recognizes the command; errors then says why each declined.
compiler, dialectThe compiler rule that matched, and the command-line syntax it is parsed with.
phase, artifactWhat the command does (preprocess, syntax-only, compile, link, …) and what it produces.
targetThe target the outputs are named for, and where it came from (argument, executable-prefix, driver-default, host-fallback).
responseFiles, argumentsThe response files (@file) the command names, the files they name too, and its arguments with them read in; only when it names one catter reads.
sourcesThe sources that get compilation database entries.
reads, writes, edgesThe files the command reads and writes, and which output is made from which inputs (the target tree's edges).
inferredOutputs the command does not name, inferred from the compiler's defaults.
diagnosticsWhat the analysis could not settle, such as an output it cannot infer or a response file it cannot read.
entriesThe compilation database entries compile-commands writes for this command.
